04

금가루 효과 적용

"가까운 매장에서 퓨어 골드를 만나보세요" 매장 안내 구간 배경에 금가루가 흩날리는 효과를 넣었습니다. 효과는 직접 만든 것이 아니라 Figma에서 만든 효과의 코드를 가져와 사용했으며, 페이지 구간에 맞게 넣어 적용하였습니다. 가져온 코드는 Canvas 2D로 입자를 그리는 방식으로, 아래와 같이 동작합니다.

  1. 입자 구성

    금색 팔레트 두 종류(기본 · 밝은 금색)를 섞고, 일부 입자는 줄기처럼 모이도록 배치되어 자연스럽게 흩날립니다.

  2. 움직임 · 반짝임

    입자마다 떨어지는 속도, 좌우 흔들림, 깜빡임 주기가 다르고, 일부는 흰빛으로 번쩍이거나 마름모 조각으로 그려집니다.

  3. 성능

    화면 면적에 비례해 입자 수를 정하고(최대 20,000개), 기기 픽셀 비율은 2배까지만 반영합니다. 영역이 화면에 보일 때만 그리도록 IntersectionObserver로 멈추고 다시 시작합니다.

  4. 반응형 · 접근성

    ResizeObserver로 영역 크기가 바뀌면 다시 그리고, 모션 축소 설정 사용자에게는 효과를 실행하지 않습니다.

금가루 입자 생성 · 그리기 JavaScript Figma에서 가져와 적용한 코드 일부 발췌 — 화면 면적 기준 입자 수, 보일 때만 그리기, 모션 축소 대응 
var canvas = document.querySelector('.pg-meet__dust');
if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;

function build() {

      twSpeed: Math.random() * 0.04 + 0.01,      // 깜빡임 주기
      flip: Math.random() < 0.22                 // 흰빛 반짝임
      /* ... */
    });
  }
}

매장 지도 · 관리자 업장 관리

퓨어 골드가 새로 출시되면서 매장 찾기 지도의 매장 데이터를 판매 제품별로 나눴습니다. 지도에서는 STELLA ARTOIS · PURE GOLD 탭으로 판매 매장을 따로 보여주고, 관리자페이지 지도관리에서는 업장마다 판매 제품을 지정하고 제품별로 걸러 볼 수 있도록 분리 · 추가하였습니다.

퓨어 골드 탭 금가루 — Figma 애니메이션을 JSON으로 적용

지도에서 PURE GOLD 탭을 선택하면 오른쪽 아래(모바일은 탭 위 왼쪽)에 병 · 잔 이미지와 금가루 애니메이션이 나타납니다. Figma 프로토타입 '금가루 + 이미지 애니메이션'의 Gold Dust 레이어 알갱이 440개의 위치 · 크기 · 색 · 회전과 이동 · 회전 · 투명도 키프레임, 이징 값을 JSON 파일(map_gold_dust.json)에 그대로 담고, 이를 Canvas에 그려 Figma 애니메이션과 같은 움직임을 재생하도록 적용하였습니다.

  • Figma 데이터 → JSON

    Figma 화면(1920×934) 기준 알갱이 440개와 키프레임 · 이징을 JSON으로 담아, 한 바퀴 3.9초 애니메이션을 퓨어 골드 탭인 동안 반복합니다.

  • 화면 크기 대응

    Figma 기준 위치를 캔버스 크기에 맞춰 줄이고, PC는 110개 · 모바일은 50개만 골라 그립니다. 병 · 잔 이미지 등장은 Figma 키프레임대로 CSS 애니메이션으로 적용했고, 지도 클릭은 막지 않도록 했습니다.
