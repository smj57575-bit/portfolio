◂ SEO · AEO · GEO ▸ Search · Answer · AI Search

SEO · AEO · GEO

검색엔진(SEO), 답변형 검색(AEO), 생성형 AI 검색(GEO)이 페이지 내용을 정확히 이해하고 인용할 수 있도록 메타 정보, 시맨틱 마크업, 구조화 데이터, 문답형 콘텐츠 구조를 함께 설계합니다.

SEO

Technical SEO Search Engine Optimization

  • Meta Title · Description
  • Open Graph · Canonical URL
  • Semantic HTML · 헤딩 계층
  • JSON-LD 구조화 데이터
AEO

답변형 검색 Answer Engine Optimization

  • 검색 의도를 반영한 질문 · 답변(Q&A) 구조
  • FAQPage 구조화 데이터
  • Question · Answer 마이크로데이터
  • 질문은 h3, 주제는 h2로 나눈 문답 계층
GEO

생성형 AI 검색 Generative Engine Optimization

  • 명확한 헤딩 계층과 섹션 구조
  • Organization · Brand 등 출처 정보 구조화
  • AI가 인용하기 쉬운 구조화된 정보 제공
