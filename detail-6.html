AI Smart 홈페이지 제작 (개인)

📅 2025년 7월 ~ 2025년 9월 👤 역할: 기획 · 웹디자인 · 웹퍼블리싱

프로젝트 개요

스마트팩토리·공작기계·CAD/CAM·PLC·센서·로봇 등 산업 자동화 솔루션을 다루는 5인 미만 기업 AI Smart의 홈페이지를 기획부터 디자인, 퍼블리싱까지 단독으로 진행한 개인 프로젝트입니다.

기존에 온라인 채널이 정리되어 있지 않은 상태에서 시작해, 회사가 전달해야 할 정보를 먼저 구조화하고 그 위에 디자인과 마크업을 얹는 순서로 작업했습니다. 제품 수가 많고 자료실·다운로드 등 외부 채널로 연결되는 경로가 많은 만큼, 방문자가 원하는 정보에 최소 단계로 도달할 수 있는 정보 구조를 만드는 데 중점을 두었습니다.

화면 미리보기

메인 화면의 PC / 모바일 구현 결과입니다. 어두운 산업 현장 이미지 위에 핵심 슬로건과 주요 액션(자료실·다운로드)을 배치해, 첫 화면에서 회사의 업종과 다음 행동이 함께 읽히도록 구성했습니다.

주요 역할 및 업무

• 정보 구조(IA) 및 페이지 기획
회사소개 / 제품소개 / 공지사항 / 자료실 / ESG로 메뉴를 정리하고, 각 페이지에 담을 콘텐츠와 우선순위를 직접 설계

• 웹디자인 및 메인 화면 구성
산업 자동화 업종에 맞는 다크 톤 비주얼과 포인트 컬러를 정의하고, 슬로건 → 제품 → 공지 → 현장 이미지 → 상담신청으로 이어지는 메인 흐름을 디자인

• 제품 슬라이더 설계
CAP 모니터링, AI-TextEditor, AI-EDIT, AI-FTP/DNC, LTS 공구길이 측정기, PROBE 자동 계측, 로봇, 공작기계, 이더넷 디바이스, CNC 시뮬레이터 등 10개 제품을 한 화면에 나열하는 대신 회전형 슬라이더로 묶어 탐색 부담을 완화

• 반응형 퍼블리싱
PC / 태블릿 / 모바일 전 구간을 대응하고, 모바일에서는 햄버거 메뉴와 세로 정렬 버튼 구조로 전환해 터치 조작에 맞는 레이아웃 제공

• 외부 채널 및 다운로드 동선 연결
NAVER·Daum 카페 자료실, 원격제어 다운로드, 국가자격 확인 모달 등 회사가 실제로 사용하는 외부 채널을 메인 화면에서 바로 접근할 수 있도록 배치

• 상담신청 폼 구현
성함·연락처·문의내용을 받는 CONTACT US 영역을 구성하고, 라벨 연결과 입력 안내를 갖춘 접근 가능한 폼으로 마크업

기술 스택

주요 코드 미리보기

※ 실제 운영 파일을 그대로 공개하는 대신, 핵심 구현 방식을 일반화한 예시 코드입니다. (회사명·도메인·내부 경로는 대표 예시로 대체)

1) 현재 슬라이드 상태를 전달하는 메인 비주얼 슬라이더

메인 비주얼의 인디케이터는 장식용 점이 아니라 button 요소로 구성해 키보드로도 슬라이드를 이동할 수 있게 했습니다. 현재 슬라이드는 aria-current로 표시하고, 화면 밖으로 밀려난 슬라이드는 hidden 처리해 보이는 상태와 스크린리더가 읽는 상태가 일치하도록 맞췄습니다.

<section class="hero" aria-roledescription="carousel" aria-label="메인 비주얼">
    <ul class="hero__slides">
        <li class="hero__slide is-active">
            <h2>스마트 기술의 모든 것, 제조 혁신의 중심이 되다</h2>
            <p>스마트팩토리부터 공작기계, CAD/CAM, PLC까지 산업 자동화의 미래를 선도합니다.</p>
        </li>
        <li class="hero__slide" hidden>...</li>
    </ul>

    <div class="hero__dots" role="group" aria-label="슬라이드 선택">
        <button type="button" class="dot is-active" aria-current="true">
            <span class="sr-only">1번 슬라이드</span>
        </button>
        <button type="button" class="dot">
            <span class="sr-only">2번 슬라이드</span>
        </button>
    </div>
</section>

<script>
const slides = document.querySelectorAll('.hero__slide');
const dots = document.querySelectorAll('.hero__dots .dot');

const goTo = (index) => {
    slides.forEach((slide, i) => {
        slide.classList.toggle('is-active', i === index);
        slide.hidden = i !== index;
    });
    dots.forEach((dot, i) => {
        dot.classList.toggle('is-active', i === index);
        if (i === index) dot.setAttribute('aria-current', 'true');
        else dot.removeAttribute('aria-current');
    });
};

dots.forEach((dot, i) => dot.addEventListener('click', () => goTo(i)));
</script>

2) 화면 폭에 따라 노출 개수가 달라지는 제품 목록

제품이 10개로 많아 화면 폭마다 한 번에 보여줄 개수를 다르게 가져갔습니다. 개수를 자바스크립트로 계산하는 대신 CSS 그리드와 미디어쿼리로 처리해, 스크립트가 실행되지 않아도 목록 자체는 정상적으로 읽히도록 구성했습니다.

<section class="product" aria-labelledby="product-title">
    <h2 id="product-title">PRODUCT</h2>
    <ul class="product__list" role="list">
        <li class="product__item">
            <a href="/product/cap-monitoring">
                <img src="/assets/img/product/cap.png" alt="">
                <strong>CAP 모니터링</strong>
            </a>
        </li>
        <li class="product__item">
            <a href="/product/ai-text-editor">
                <img src="/assets/img/product/text-editor.png" alt="">
                <strong>AI-TextEditor</strong>
            </a>
        </li>
    </ul>
</section>
.product__list {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 24px;
}

@media (max-width: 1024px) {
    .product__list { grid-template-columns: repeat(2, 1fr); gap: 16px; }
}

@media (max-width: 640px) {
    .product__list { grid-template-columns: 1fr; gap: 12px; }
}

3) 라벨과 입력 안내를 연결한 상담신청 폼

상담신청 폼은 placeholder에 의존하지 않고 label을 명시적으로 연결했습니다. 필수 항목은 required와 aria-required로 함께 표시하고, 입력 형식 안내는 aria-describedby로 연결해 스크린리더에서도 조건이 함께 전달되도록 했습니다.

<form class="contact-form" action="/contact" method="post">
    <div class="field">
        <label for="contact-name">성함</label>
        <input type="text" id="contact-name" name="name" required aria-required="true">
    </div>

    <div class="field">
        <label for="contact-tel">연락처</label>
        <input type="tel" id="contact-tel" name="tel"
               required aria-required="true"
               aria-describedby="tel-help">
        <p id="tel-help" class="field__help">숫자만 입력해 주세요. (예: 01012345678)</p>
    </div>

    <div class="field">
        <label for="contact-message">문의내용</label>
        <textarea id="contact-message" name="message" rows="6"></textarea>
    </div>

    <button type="submit" class="btn-submit">상담 신청하기</button>
</form>
